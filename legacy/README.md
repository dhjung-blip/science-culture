# `legacy/` — not used by the manuscript

Nothing in this directory produces a number, table, or figure that appears in the paper. It is
retained so that the development history of the project is inspectable, not so that anyone
replicates from it. If you are here to reproduce the paper, go back to `REPRODUCIBILITY.md`.

## Contents

| Path | What it is | Why it is not in the paper |
|---|---|---|
| `replicate_paper.py` | Entry point for an earlier 20-country specification with 17 variables and five policy scenarios | Superseded by the 44-country specification. Its country set includes two economies absent from the analysis panel, and its reported R² (0.51) and category shares differ from every published figure |
| `single_country_scenario.py` | Local SHAP decomposition for a single country plus policy what-if | Excluded on identification grounds. See Section 5.4, item 11: a cross-sectional model learns differences between countries and cannot be used to extrapolate the effect of an intervention within one country. It imports `scenario_simulator` from `code/`, which stays there as a pipeline stage; no number it produces is reported |
| `dashboard/` | React and Vite interface for browsing results | Presentation only; produces no estimate |
| `data_v1/` | The two canonical CSVs **before** the release-time column removal | `replicate_paper.py` and `dashboard/scripts/build_data.py` reference the five removed columns and will not run against the released files. These copies keep the legacy path executable without putting undocumented columns into the released data |

## The five columns

`self_efficacy`, `avg_proj_duration`, `admin_burden_ratio`, `researcher_retire_age`, and
`competitiveness` were generated by the prototype pipeline for constructs that had no
harmonized international source. They were dropped from the feature groups before any analysis
reported in the manuscript was run, but remained in the saved data files. Because they are
populated for only 18 of the 44 countries — the prototype's country set — leaving them in the
released files would present a reader with values of unclear origin. `COLUMN_REMOVAL_LOG.md`
records the removal, the verification that no reported estimate changes, and the exact country
list.

## Running the legacy path

```bash
cp legacy/data_v1/*.csv analysis/canonical/     # restores the pre-removal files
uv run --no-sync python legacy/replicate_paper.py
git checkout analysis/canonical/                # restore the released files afterwards
```

Do not report anything obtained this way as a result of the paper.
